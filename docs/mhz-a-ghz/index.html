MHz a GHz

Conversión de mhz a ghz, con calculadora interactiva.

1 MHz = 0.001 GHz. Esta conversión de frecuencia se usa frecuentemente para ingeniería de radiofrecuencia y electrónica y telecomunicaciones. Fórmula: GHz = MHz × 0.001.
