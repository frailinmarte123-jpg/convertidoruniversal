Conversión de mhz a hz, con calculadora interactiva.

1 MHz = 1,000,000 Hz. Esta conversión de frecuencia se usa frecuentemente para electrónica y telecomunicaciones y música y producción de audio. Fórmula: Hz = MHz × 1,000,000.
