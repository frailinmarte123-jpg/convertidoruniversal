Conversión de mpg (millas/galón us) a km/l, con calculadora interactiva.

1 MPG (millas/galón US) = 0.425144 km/L. Esta conversión de eficiencia de combustible se usa frecuentemente para entender etiquetas de eficiencia energética y comparar la eficiencia entre vehículos. Fórmula: km/L = 100 ÷ (235.214583 ÷ MPG).
