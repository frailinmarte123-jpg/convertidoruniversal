Conversión de km/l a l/100 km, con calculadora interactiva.

1 km/L = 100 L/100 km. Esta conversión de eficiencia de combustible se usa frecuentemente para comparar la eficiencia entre vehículos y planificar el gasto de un viaje largo. Fórmula: L/100 km = 100 ÷ (km/L).

El consumo de combustible mide la eficiencia de un vehículo: cuánto combustible necesita para recorrer cierta distancia (o viceversa). Es clave para comparar autos y planificar gastos de viaje.
