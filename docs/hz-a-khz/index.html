1 Hz equivale a 0.001 kHz. Esta conversión se usa frecuentemente en corriente eléctrica doméstica, audio (frecuencias audibles) y transmisión de radio AM.

Fórmula

kHz = Hz × 0.001

Ejemplos comunes

  • 60 Hz ≈ 0.06 kHz (la corriente eléctrica doméstica)
  • 5.0000e+9 Hz ≈ 5,000,000 kHz (una red wifi moderna)
  • 3.0000e+9 Hz ≈ 3,000,000 kHz (un procesador de computadora)

Aprende más sobre esta conversión

¿Qué diferencia hay entre hz y khz? Ambas unidades pertenecen al mismo sistema (sistema internacional (SI)); la diferencia es de escala, no de sistema: 1 hz equivale exactamente a 0.001 khz.

Esta conversión se usa frecuentemente en corriente eléctrica doméstica, audio (frecuencias audibles) y transmisión de radio AM.

La frecuencia mide cuántas veces ocurre un evento por segundo (Hertz). Es central en electrónica, telecomunicaciones y audio. Hz corresponde al sistema internacional (SI).

Preguntas frecuentes

¿Cuántos khz son 1 hz?

1 Hz equivale a 0.001 kHz.

¿Cómo convertir hz a khz?

Multiplica la cantidad en hz por 0.001. Fórmula: kHz = Hz × 0.001.

¿Para qué se usa la conversión de hz a khz?

Se utiliza principalmente en corriente eléctrica doméstica, audio (frecuencias audibles) y transmisión de radio AM.
